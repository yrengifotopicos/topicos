# 📘 Tópicos avanzados Base de datos (Repositorio)

📚 Repositorio con apunte(s), ejemplos y ejercicios prácticos correspondientes al curso **Tópicos de avanzados de bases de datos**.

## 🛠️ Rama: `develop`

🔄 Contiene la versión en desarrollo del proyecto. Aquí se integran nuevos temas, ejemplos y correcciones antes de fusionar a la rama principal (`produccion`).

---

## 🗂️ Estructura del repositorio

- 🧾 **emprendedores.sql** — Archivo con las **queries para crear la base de datos** en PostgreSQL.
- 📝 **dbdiagram.io** — Archivo en formato Markdown para **visualizar y modificar el esquema ER** usando [dbdiagram.io](https://dbdiagram.io).
- 🖼️ **ER_emprendedores.png** — Imagen del **esquema entidad-relación (ER)** de la base de datos.
